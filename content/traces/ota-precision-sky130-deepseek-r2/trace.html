1: # Public measurement contract: OTA-PRECISION-SKY130
2: 
3: These methods and selected spec.json limits are implementation requirements.
4: Native validation is not implied by this document or an offline test result.
5: No method refers to a DUT-internal node or device role. A follower window is not
6: independent ICMR or distortion-qualified output swing.
7: 
8: ## DC, ports and operating point
9: 
10: Connect output to VINN externally, VINP to the input source, CL to external ground.
11: Meter all six DUT ports with zero-volt sources pointing INTO DUT. Save voltages,
12: signed currents, KCL residual and the sum of VSS-relative terminal powers.
13: An ideal output clamp must not create a false operating point. IREF is noiseless,
14: AC zero, constant in supply-ripple tests and enters IBIAS from VSS.
15: 
16: Sweep the card's input interval at 5 mV spacing, including both endpoints. Retain
17: all samples; take maximum absolute follower error and maximum signed-port power
18: only when every required sample is valid. Input loading and IBIAS compliance also
19: apply at every DC point. Save the independently solved output at all step endpoints.
20: Device diagnostics are optional; their absence is not a functional failure.
21: A native DC solution alone is not proof of temporal stability.
22: 
23: ## External-loop return ratio
24: 
25: Keep DC feedback and the real CL. e is the inverting-input side and f the output
26: side. Probe V(e)-V(f) with a DC-zero voltage source; inject DC-zero current from
27: VSS to e. Run voltage injection (V=1, I=0) and current injection (V=0, I=1) in one
28: ngspice process. Normalize actual source phasors and use i_f=-I(Vprobe):
29: 
30: A=i_f/Iinj and C=V(e,VSS)/Iinj in the current run;
31: B=i_f/Vinj and D=V(e,VSS)/Vinj in the voltage run.
32: 
33: L = [2(AD-BC)-A+D] / [2(BC-AD)+A-D+1].
34: 
35: Use the 1+L sign convention, not an automatically sign-flipped curve. Preserve
36: both raw paths and identical frequency grids/DC/model realization. Numerical
37: denominator cancellation uses the prescribed relative guard 1e-10; unresolved
38: values cannot become infinite gain or a passing margin. Record the ratio of
39: absolute denominator to the sum of its term magnitudes.
40: 
41: Sweep 10 Hz-1 GHz at 50 points/decade for SKY130. All samples finite,
42: frequencies increasing, endpoint relative error <=1e-7 and log10 spacing
43: <=0.020001. Low-frequency gain is 20 log10(abs(L)) at 10 Hz, not an invented DC
44: limit. Reuse all-crossing extraction: interpolate linearly in log frequency,
45: select the first positive-to-negative 0 dB crossing, unwrap phase from the first
46: principal phase with adjacent changes within +/-180 degrees. Report each unity
47: crossing's frequency, unwrapped phase and gain direction, plus touches/boundaries.
48: Record whether any later sample exceeds 0 dB + 1e-6 dB after the selected crossing.
49: These diagnostics have no PASS/MISS verdict. Do not
50: convert the crossing phase into a phase margin or report a gain-margin scalar.
51: Only the 10 Hz gain and first descending crossing frequency are scored here.
52: A missing selected crossing cannot pass the bandwidth requirement. Invalid or incomplete
53: AC data remains a measurement failure.
54: 
55: This two-port measurement is an external-loop metric. It does not certify every
56: internal feedback mode of an arbitrary circuit. Time-domain requirements remain
57: separate; global internal-mode certification is not a new acceptance gate.
58: Method basis: Tian et al., Fig. 7 and eqs. 21-23/30,
59: https://kenkundert.com/docs/cd2001-01.pdf .
60: 
61: ## CMRR: bounded DC balance, then two AC paths
62: 
63: Fix average input to the card's VCM and target VOUT=VCM. Set
64: VINP=VCM+VD0/2 and VINN=VCM-VD0/2 without output clamp or AC servo.
65: Try VD0=0 first. Success means abs(VOUT-VCM)<=10 uV at a valid OP. Otherwise
66: try endpoints -10 mV and +10 mV. Accept an endpoint meeting tolerance or require
67: a negative/positive residual bracket in that order. Bisect at most 32 times,
68: retaining each VD0, VOUT and status. There are at most 35 explicit OP commands.
69: Failure to bracket/converge is NO_VALID_BALANCED_OP / BALANCE_UNRESOLVED, not
70: proof of topology infeasibility. No adaptive range expansion or silent bias fix.
71: 
72: At the successful unclamped OP keep VD0 fixed. Differential AC is +0.5/-0.5 V
73: (unit difference); common AC is +1/+1 V (unit common mode). Other sources are AC
74: zero. At exactly 1 kHz, report 20 log10(abs(Ad/Acm)), the input phasors and both
75: paths. Zero/underflow/nonfinite ratios or a missing valid OP are invalid evidence,
76: not automatic infinite rejection.
77: 
78: Perform the bounded control loop and both AC paths in ONE native process and log
79: explicit OP count and implicit AC operating-point work. Timeout stops that case;
80: no unlimited loop or free process retries. The offline callback is an algorithm
81: oracle, not permission to count 35 separate processes as one. The official ngspice
82: control tutorial documents alter/op/loop flows and multiple analyses in one run:
83: https://ngspice.sourceforge.io/ngspice-control-language-tutorial.html .
84: 
85: ## Transients
86: 
87: Use card-specific levels, edge start/duration, stop time and maximum sample gap.
88: Each transient uses its own independently solved DC endpoints. Measure slew from
89: edge start: an output which crosses 20/80% during the finite input edge remains
90: valid. Require complete finite increasing samples throughout the observation.
91: Edges start at 1 us, take 10 ns and have 20 us post-edge observation.
92: The maximum sample gap is 1 ns, divided by four for numerical refinement.
93: Full verification uses 138 public plus 72 independent cases.
94: 
95: Settling is final interpolated entry that remains within 1% of INPUT step amplitude
96: about the independently solved destination DC OUTPUT, measured from edge start.
97: DC tracking is a separate required check. Wrong static levels therefore cannot
98: pass by tail normalization. Complete unsettled data yields null settling and an
99: observation-time lower bound; a bound beyond the limit is MISS. Short or missing
100: waveforms are invalid, not fast settling. Small-step overshoot is excursion beyond
101: target divided by absolute independent DC output transition. Large-step slew uses
102: the first ordered direction-correct 20/80% crossings after the edge starts. Retain
103: recrossings and characterize large-step overshoot; don't add a new waveform score.
104: 
105: ## Noise, PSRR and verdicts
106: 
107: Noise uses the real follower at VCM and the same-circuit signal transfer. Save
108: input-referred ASD, integrate its squared PSD in linear frequency with trapezoids
109: and boundary interpolation, then square root: 10 Hz-100 kHz at 50 points/decade.
110: Keep 10/100/1000 Hz lower-cutoff integrals as diagnostics.
111: 
112: PSRR uses two AC paths at the same follower OP: VDD=1/input=0 then VDD=0/input=1.
113: IREF and VCM do not follow supply ripple. Save phasors and calculate
114: 20 log10(abs(Hsignal/Hsupply)) at 1 kHz and 1 MHz, not an LDO supply/output-only
115: formula. Invalid/zero transfers do not become favorable zero noise/infinite PSRR.
116: 
117: All required standard cases must produce valid passing metrics on one DUT.
118: Inclusive limits are compared without rounding. Keep failed metrics and unknowns;
119: partial execution is not a completed PASS or a substituted last-good design.
120: Independent evaluation uses the captured standard grid for every required case.
121: Numerical precision comparisons use a separately authorized developer allocation.
122: A standard-grid PASS is not a per-submission convergence proof.

Design summary

Topology (two-stage Miller OTA in dut.spice):

  • NMOS input pair W=40/L=2 with a 40 µA tail (W=40/L=1), biased from the 10 µA IBIAS pin via an NMOS diode
  • PMOS mirror load W=100/L=2
  • PMOS common-source output W=100/L=1 (m=4, 100 µA) with an IBIAS-mirrored NMOS sink W=100/L=4 (m=4)
  • Miller compensation 3.6 pF + 800 Ω nulling resistor

Key design rules discovered by measurement:

  1. Offset nulling: matching the output device's current density to the mirror's (Vov6 ≈ Vov3 − 25 mV) cancels the systematic input offset. A 1.2 mV follower error collapsed to 48 µV at N and ≤0.413 mV worst case.
  2. Headroom: at VDD=1.62 V/cold the input pair's drains get squeezed (V_B = VDD−|Vgs3|); a wide, low-Vov output device plus small Vov mirror fixes a 30–60 mV loop-gain collapse that affected every early variant.
  3. Stability/PSRR: PSRR at 1 MHz is loop-gain limited (≈UGF/1 MHz). Shrinking the mirror devices (cutting the mirror-pole capacitance) allowed Cc=3.6 pF, giving UGF 10.8–15.7 MHz with phase −109°…−122°.

Verified worst case over all 138 public cases (9 PVT × 2 loads): DC tracking 0.413 mV (<0.5), LF loop gain 83.4 dB (>80), UGF 10.8 MHz (>1), overshoot 8.1% (<10%), slew 6.4 V/µs (>0.5), settling 0.082 µs (<2 µs), noise 17 µV (<20), PSRR 80.2 dB@1 kHz / 21.8 dB@1 MHz, CMRR 78 dB, power 0.48 mW (<0.6), W·L = 2610 µm² (<5000), C = 3.6 pF (<20 pF), IBIAS compliant.
