  • PMOS pass device (short L ⇒ small gate cap ⇒ no low-frequency gate pole).
  • NMOS source follower ("flipped voltage follower" style) buffers the pass gate, so the EA's high-impedance output only drives ~tens of fF instead of the pass cap + Miller; this pushes the internal pole >1 MHz while the load pole stays dominant.
