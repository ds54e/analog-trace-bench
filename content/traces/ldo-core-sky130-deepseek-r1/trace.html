7: ## DC: port signs, cost and absolute voltage
8: 
9: All four DUT ports have zero-volt meters. Load and decap return to external node
10: `0`, not the DUT side of Vground. Thus the regulator ground-current measurement
11: does not include delivered load current.
12: 
13: `Iin=i(Vpin)`, `Iref=i(Vrefmeter)` enter VIN/VREF;
14: `Iout=i(Voutmeter)`, `Ignd=i(Vground)` leave VOUT/VSS.
15: Check `Iin+Iref-Iout-Ignd` against an absolute 1 nA tolerance. A failed residual is invalid measurement,
16: not a favorable low-current result. Save signed
17: currents, voltages and OP status. The DC overhead is
18: `max(Iin-Iout,0)+max(Iref,0)`, with a separate `abs(Iref)<=1 uA` gate. Reference
19: sourcing is charged, and sinking is already reflected in Iin-Iout. This is not
20: no-load IQ. Apply the minimum-load cap only at the minimum load, and the general
21: cap at all DC loads. Missing currents or invalid OP cannot become zero overhead.
22: Dissipation is `VIN*Iin+VREF*Iref-VOUT*Iout`, using VSS-relative voltages. Keep it
23: as characterization; input power contains useful load power. No dynamic-energy
24: score and no DC-overhead interpretation of capacitor charging during transients.
25: 
26: Measure error from each card's fixed target, not a candidate's own output:
27: SKY130 DC/recovery band is 1.176-1.224 V, envelope 1.104-1.296 V;
28: ADM45 DC/recovery band is 0.784-0.816 V, envelope 0.736-0.864 V.

30: and VIN condition. A transient tail is not a DC solution. Exploration may request
31: a single transient without separate DC cases: recovery uses the fixed target,

#!/usr/bin/env python3
"""Participant measurement and submission client; authority stays with the broker."""
import argparse
import json
from pathlib import Path
import socket
import sys


def parser():
    p=argparse.ArgumentParser(prog='atb-client',description=__doc__)
    p.add_argument('--request',type=Path,help='Read a complete request from a JSON file')
    sub=p.add_subparsers(dest='command')
    for name in ('help','status','validate'):
        sub.add_parser(name)
    for name in ('estimate','measure'):
        s=sub.add_parser(name)
        if name=='measure':s.add_argument('--id',dest='experiment_id',required=True)
        s.add_argument('--analysis',required=True);s.add_argument('--pvt',required=True)
        s.add_argument('--cl',type=float,help='Load capacitance in farads')
        s.add_argument('--seed',type=int)
    sub.add_parser('submit').add_argument('--rationale',required=True)
    return p


def request_from(args,workspace):
    if args.request:
        if args.command:raise ValueError('--request cannot be combined with a command')
        request=json.loads(args.request.read_text())
    else:
        request={'action':args.command or 'status'}
        for key in ('experiment_id','analysis','pvt','cl','seed','rationale'):
            value=getattr(args,key,None)
            if value is not None:request[key]=value
    if not isinstance(request,dict):raise ValueError('Request must be a JSON object')
    if request.get('action') not in ('help','status','validate','estimate','measure','submit'):
        raise ValueError('Unknown participant action')
    if request['action'] in ('validate','measure','submit'):
        task=workspace/'task.json'
        if task.exists() and json.loads(task.read_text()).get('design_format')=='netlist':
            request['design']={'netlist':(workspace/'dut.spice').read_bytes().decode('utf-8')}
        else:request['design']=json.loads((workspace/'design.json').read_text())
    return request


def exchange(request,address):
    with socket.socket(socket.AF_UNIX,socket.SOCK_STREAM) as sock:
        sock.connect(str(address))
        sock.sendall((json.dumps(request,allow_nan=False)+'\n').encode())
        with sock.makefile('r') as stream:
            reply=json.loads(stream.readline())
    if not isinstance(reply,dict):raise ValueError('Broker reply must be a JSON object')
    return reply


def main(argv=None,workspace=Path('/workspace'),address=Path('/run/atb/broker.sock')):
    args=parser().parse_args(argv)
    try:reply=exchange(request_from(args,Path(workspace)),address)
    except (OSError,ValueError,UnicodeError) as exc:
        # Do not include request contents, circuit bytes or provider credentials.
        reply={'ok':False,'error':type(exc).__name__,'reason':'Cannot read the request/design or exchange a valid broker reply.'}
    print(json.dumps(reply,ensure_ascii=False,indent=2,allow_nan=False))
    return 0 if reply.get('ok') is True else 1


if __name__=='__main__':sys.exit(main())
