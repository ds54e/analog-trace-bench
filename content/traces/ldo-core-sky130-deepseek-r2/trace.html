3: These definitions apply to both formal task cards. The implementation must be
4: checked natively with the pinned models; offline algebra is not that evidence.
5: Do not inherit the old fixed-OTA threshold or case-count definitions.

7: ## DC: port signs, cost and absolute voltage
8: 
9: All four DUT ports have zero-volt meters. Load and decap return to external node
10: `0`, not the DUT side of Vground. Thus the regulator ground-current measurement
11: does not include delivered load current.
12: 
13: `Iin=i(Vpin)`, `Iref=i(Vrefmeter)` enter VIN/VREF;
14: `Iout=i(Voutmeter)`, `Ignd=i(Vground)` leave VOUT/VSS.
15: Check `Iin+Iref-Iout-Ignd` against an absolute 1 nA tolerance. A failed residual is invalid measurement,
16: not a favorable low-current result. Save signed
17: currents, voltages and OP status. The DC overhead is
18: `max(Iin-Iout,0)+max(Iref,0)`, with a separate `abs(Iref)<=1 uA` gate. Reference
19: sourcing is charged, and sinking is already reflected in Iin-Iout. This is not
20: no-load IQ. Apply the minimum-load cap only at the minimum load, and the general
21: cap at all DC loads. Missing currents or invalid OP cannot become zero overhead.
22: Dissipation is `VIN*Iin+VREF*Iref-VOUT*Iout`, using VSS-relative voltages. Keep it
23: as characterization; input power contains useful load power. No dynamic-energy
24: score and no DC-overhead interpretation of capacitor charging during transients.
25: 
26: Measure error from each card's fixed target, not a candidate's own output:
27: SKY130 DC/recovery band is 1.176-1.224 V, envelope 1.104-1.296 V;
28: ADM45 DC/recovery band is 0.784-0.816 V, envelope 0.736-0.864 V.
29: Final verification evaluates independent DC solutions at every required load
30: and VIN condition. A transient tail is not a DC solution. Exploration may request
31: a single transient without separate DC cases: recovery uses the fixed target,
32: and the transient deck records its own operating point and initial hold. Such a
33: request does not establish DC compliance at every load.
34: Line/load regulation and actual signed currents remain available for diagnosis.

36: ## Prescribed loads and windows
37: 
38: | Profile | Levels | Time definition |
39: |---|---|---|
40: | light_heavy | card minimum -> maximum -> minimum | 1 us pre-hold, 100 ns edges, 2 us high/low plateaus |
41: | mid_heavy | card middle -> maximum -> middle | same |
42: | burst | minimum <-> maximum, 8 pulses | 100 ns edges, 200 ns high/low plateaus, 1 us extra final tail |
43: 
44: SKY130 levels are 50 uA/0.5 mA/2 mA; ADM45 levels 25 uA/0.25 mA/1 mA.
45: PWL loads are explicit electrical stimuli, not data from an RTL block. Reference
46: and VIN are fixed in load tests. The regulator stays enabled; start from its DC
47: solution without `.ic`/`uic`. The 1 us pre-hold must also satisfy the DC voltage
48: band; do not hide pre-existing oscillation by starting the score at the edge.
49: 
50: Recovery starts at each isolated edge START, not its end. Interpolate the last
51: entry into the target +/-2% band which stays in the band until the next edge
52: or record end. Require <=500 ns. Record extrema and absolute target-relative
53: errors during the whole transition/window. A flat but wrong voltage fails.
54: A complete trace ending outside the band has null recovery and an observation-
55: time lower bound; a bound exceeding the limit is MISS, not missing measurement.
56: Short/nonfinite/unordered/insufficiently sampled records are invalid evidence.
57: 
58: For bursts score the absolute envelope through **all** pulses, then recovery
59: only after the final falling edge. Do not apply a 500 ns per-edge settling
60: requirement to a 200 ns plateau. Total burst duration is 6.8 us, including its
61: extra tail. Record peak-to-peak output as characterization, not a new stability
62: score. Isolated profiles are 5.2 us. Positive and negative excursions both count.
63: 
64: Maximum timestep and requested output step are 0.5 ns. Check stored sample gaps
65: against 0.5 ns with relative slack 1e-9, using actual timestamps rather than
66: assuming the requested output grid was delivered. Qualify convergence and compare
67: representative extremes with a finer grid before release. This is finite-window,
68: sampled evidence, not proof against every internal or unobserved oscillation.

70: ## Line and PSRR: mandatory characterization, not scoring
71: 
72: Line: use each card's VIN minimum -> maximum -> minimum, 200 ns edges, maximum
73: load, reference fixed. Report the same target-relative windows. PSRR: valid
74: nominal OP at minimum and maximum load; VIN AC=1, reference/load AC=0.
75: `PSRR=20*log10(abs(VIN_ac/VOUT_ac))`. Save actual phasors at 1 kHz and 1 MHz and
76: the intervening sweep. This is supply-to-output rejection, not the OTA signal-
77: normalized ratio. Zero/underflow/nonfinite transfer is unresolved/invalid, not
78: infinite PASS. A non-regulating or oscillating state cannot provide a qualified
79: PSRR result merely because an AC command ran.

"""Participant measurement and submission client; authority stays with the broker."""
import argparse
import json
from pathlib import Path
import socket
import sys


def parser():
    p=argparse.ArgumentParser(prog='atb-client',description=__doc__)
    p.add_argument('--request',type=Path,help='Read a complete request from a JSON file')
    sub=p.add_subparsers(dest='command')
    for name in ('help','status','validate'):
        sub.add_parser(name)
    for name in ('estimate','measure'):
        s=sub.add_parser(name)
        if name=='measure':s.add_argument('--id',dest='experiment_id',required=True)
        s.add_argument('--analysis',required=True);s.add_argument('--pvt',required=True)
        s.add_argument('--cl',type=float,help='Load capacitance in farads')
        s.add_argument('--seed',type=int)
    sub.add_parser('submit').add_argument('--rationale',required=True)
    return p


def request_from(args,workspace):
    if args.request:
        if args.command:raise ValueError('--request cannot be combined with a command')
        request=json.loads(args.request.read_text())
    else:
        request={'action':args.command or 'status'}
        for key in ('experiment_id','analysis','pvt','cl','seed','rationale'):
            value=getattr(args,key,None)
            if value is not None:request[key]=value
    if not isinstance(request,dict):raise ValueError('Request must be a JSON object')
    if request.get('action') not in ('help','status','validate','estimate','measure','submit'):
        raise ValueError('Unknown participant action')
    if request['action'] in ('validate','measure','submit'):
        task=workspace/'task.json'
        if task.exists() and json.loads(task.read_text()).get('design_format')=='netlist':
            request['design']={'netlist':(workspace/'dut.spice').read_bytes().decode('utf-8')}
        else:request['design']=json.loads((workspace/'design.json').read_text())
    return request


def exchange(request,address):
    with socket.socket(socket.AF_UNIX,socket.SOCK_STREAM) as sock:
        sock.connect(str(address))
        sock.sendall((json.dumps(request,allow_nan=False)+'\n').encode())
        with sock.makefile('r') as stream:
            reply=json.loads(stream.readline())
    if not isinstance(reply,dict):raise ValueError('Broker reply must be a JSON object')
    return reply


def main(argv=None,workspace=Path('/workspace'),address=Path('/run/atb/broker.sock')):
    args=parser().parse_args(argv)
    try:reply=exchange(request_from(args,Path(workspace)),address)
    except (OSError,ValueError,UnicodeError) as exc:
        # Do not include request contents, circuit bytes or provider credentials.
        reply={'ok':False,'error':type(exc).__name__,'reason':'Cannot read the request/design or exchange a valid broker reply.'}
    print(json.dumps(reply,ensure_ascii=False,indent=2,allow_nan=False))
    return 0 if reply.get('ok') is True else 1

def saved_finish(session, message, database=None):
    """Read only this invocation's final assistant, never another session."""
    database = database or Path.home()/'.local/share/opencode/opencode.db'
    with sqlite3.connect(database.resolve().as_uri()+'?mode=ro', uri=True) as db:
        row = db.execute('SELECT data FROM session_message WHERE session_id=? AND id=? AND type=?',
                         (session, message, 'assistant')).fetchone()
    if row is None:
        raise ValueError('final assistant missing from private session')
    data = json.loads(row[0])
    if data.get('error') or not data.get('time', {}).get('completed'):
        raise ValueError('final assistant failed or did not settle')
    if data.get('finish') == 'length' and any(p.get('type') == 'tool' for p in data.get('content', [])):
        raise ValueError('truncated tool response requires review')
    return data.get('finish')


def terminal_assistant(session, observed_message, database=None):
    """CLI rendering can omit entire steps; use the settled private session tail."""
    database = database or Path.home()/'.local/share/opencode/opencode.db'
    with sqlite3.connect(database.resolve().as_uri()+'?mode=ro', uri=True) as db:
        row = db.execute('SELECT id FROM session_message WHERE session_id=? AND type=? '
                         'AND seq >= (SELECT seq FROM session_message WHERE session_id=? AND id=?) '
                         'ORDER BY seq DESC LIMIT 1',
                         (session, 'assistant', session, observed_message)).fetchone()
    if row is None:
        raise ValueError('private session tail missing or older than observed response')
    return row[0], saved_finish(session, row[0], database)


def receipt(decision, **fields):
